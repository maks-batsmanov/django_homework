# Django проект "Мой магазин"

Простой интернет-магазин на Django с двумя страницами: главная и контакты.

## Технологии
- Python 3.x
- Django
- Bootstrap 5

## Требования
- Python 3.10 или выше
- PostgreSQL 13 или выше
- Poetry

## Как работает программа
- В терминале ввести команду:
```commandline
python manage.py runserver
```
- В браузере перейти по адресу:
```commandline
http://127.0.0.1:8000/
```

## Установка и запуск

### 1. Клонировать репозиторий
```
git clone https://github.com/ваш-логин/django_homework.git
cd django_homework
```

### 2. Создать и активировать виртуальное окружение

```
python -m venv venv
source venv/bin/activate  # Linux/macOS
venv\Scripts\activate     # Windows
```

### 3. Установить зависимости

```poetry install```

### 4. Запуск 

- В терминале ввести команду:
```commandline
python manage.py runserver
```

- В браузере перейти по адресу:
```commandline
http://127.0.0.1:8000/
```
